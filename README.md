# BAAZ - India's No. 1 Pulley Manufacturer Website

A modern, responsive website for **BAAZ** (Kalgidhar Auto Mobiles) - India's leading pulley manufacturer based in Bawana Industrial Area, Delhi.

## 🚀 Tech Stack

- **React 18** - Modern UI library
- **Vite** - Fast build tool
- **Tailwind CSS** - Utility-first CSS
- **Framer Motion** - Animations
- **Lucide React** - Beautiful icons

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Features

- ✅ Modern, industrial-themed design
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Smooth animations with Framer Motion
- ✅ Product catalog with filtering
- ✅ Contact form
- ✅ WhatsApp integration
- ✅ SEO optimized
- ✅ Fast loading with Vite

## 🛠️ Customization

1. **Company Info**: Update contact details in `Contact.jsx` and `Footer.jsx`
2. **Products**: Modify product list in `Products.jsx`
3. **Colors**: Customize theme in `tailwind.config.js`
4. **Content**: Update text content in respective components

## 📱 Sections

1. **Hero** - Eye-catching landing with animated pulley graphic
2. **About** - Company history and values
3. **Products** - Product catalog with category filtering
4. **Why Choose Us** - Key differentiators
5. **Process** - Order to delivery workflow
6. **Clients** - Industries served & testimonials
7. **Contact** - Enquiry form with contact details
8. **Footer** - Links and social media
